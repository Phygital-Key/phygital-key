# Test vectors

`vectors.json` holds the shared test cases for PKA v0.1. **Every implementation, in any language, must pass every vector.**

Each vector has:

- `input.approval`: the approval string (base64url)
- `input.request`: the request the verifier is about to act on
- `input.aud`, `input.level`: who the verifier is and the lowest level it accepts
- `input.now`: the time, in Unix seconds
- `input.keyring`, `input.config`: trusted keys, allowed origins and RP IDs
- `input.seen_ids`: approval ids already used
- `expected`: `{"ok": true}` or `{"ok": false, "error": "<CODE>"}`

The file is generated by `crates/phygital-key-testgen` with fixed keys and deterministic signatures, so it never changes unless the generator does. CI checks this.

`keys/test-keys.json` holds the private test keys. **TEST ONLY: they are public. Never trust them anywhere.**
